## Предметная область

**Корпоративный мессенджер ГУАП / Сервис внутренней коммуникации для университета**

Информационная система, предназначенная для организации внутреннего взаимодействия между студентами, преподавателями и сотрудниками университета.

Основные функции системы:

* обмен мгновенными сообщениями;
* групповые чаты;
* каналы подразделений университета;
* интеграция с расписанием университета;
* обмен учебными материалами;
* система уведомлений.

Выбранная предметная область используется как основа для выполнения всех практических работ.

### Практическая работа №2 — ERD & Data Dictionary

**Разработка ER-диаграммы и словаря данных**

[Перейти к практической работе №2 →](Практическая%20работа%20№2.%20ERD/)

Разработана логическая модель данных (ERD) из 15 сущностей предметной области с указанием PK/FK, описанием связей (включая M:M через связующие сущности) и словарём данных. Модель соответствует требованиям 3NF.

Исходный файл диаграммы — `.drawio`, в папке также есть экспортированное изображение и отчёт в PDF.
