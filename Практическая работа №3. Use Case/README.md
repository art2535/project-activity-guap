## Основные акторы и сценарии

**Пользователь (студент / преподаватель / сотрудник ГУАП):**
- аутентификация и работа с профилем;
- создание и управление чатами (личные, групповые, каналы);
- обмен сообщениями (текст, файлы, reply, пересылка);
- реакции, поиск, уведомления.

**Администратор:**
- управление рассылками (Broadcasts);
- просмотр логов и метрик;
- управление сессиями пользователей (в т.ч. принудительное завершение);
- health-checks и настройка политик безопасности / rate limiting.

На диаграммах представлены связи **include**, **extend** (с точками расширения и условиями) и обобщение.
