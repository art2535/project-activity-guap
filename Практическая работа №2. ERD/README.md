## Диаграмма

### ER-диаграмма (логическая модель данных)

![Диаграмма ERD](Диаграмма%20ERD.drawio.png)

Логическая модель содержит **15 сущностей** предметной области (чаты, сообщения, пользователи, роли, статусы, настройки, сеансы, push-подписки, рассылки и др.). На диаграмме явно указаны названия сущностей, полный список атрибутов, первичные (PK) и внешние (FK) ключи.

Служебные таблицы транспорта сообщений (OutboxMessage, OutboxState, InboxState), журнал миграций и логи приложения в модель не включены.

---

## Основные связи

| Связь | Тип | Реализация |
|-------|-----|------------|
| Users ↔ Roles | M:M | через User_Roles |
| Users ↔ Chats | M:M | через Chat_Participants (Role, Join_Date) |
| Users → Chats (создатель) | 1:M | Chats.User_ID |
| Chats → Messages | 1:M | Messages.Chat_ID |
| Users → Messages | 1:M | Messages.Sender_ID |
| Messages → Attachments | 1:M | — |
| Messages / Users → Reactions | 1:M | — |
| Users → Notifications | 1:M | — |
| Users ↔ User_Statuses | 1:1 | User_ID как PK+FK |

Модель приведена к **третьей нормальной форме (3NF)**.
