# Практическая работа №4 — User Story

## Тема

**Разработка пользовательских историй (User Stories) для информационной системы «Корпоративный мессенджер ГУАП».**

## Цель работы

Сформировать требования к системе в виде пользовательских историй, описывающих потребности основных пользователей и ожидаемый результат взаимодействия с системой.

## Предметная область

**Корпоративный мессенджер ГУАП / сервис внутренней коммуникации для университета.**

Система предназначена для взаимодействия студентов, преподавателей и сотрудников университета и предусматривает:

- обмен мгновенными сообщениями;
- групповые чаты;
- каналы подразделений университета;
- интеграцию с расписанием;
- обмен учебными материалами;
- систему уведомлений.

## Результат

В рамках практической работы подготовлен отчёт с пользовательскими историями для выбранной предметной области.

Пользовательские истории сформулированы с точки зрения пользователей системы и описывают:

- **кто** выполняет действие;
- **какую потребность** необходимо реализовать;
- **зачем** пользователю нужна эта возможность.

Формат пользовательской истории:

> **Как** [роль пользователя],  
> **я хочу** [действие / возможность],  
> **чтобы** [ожидаемая ценность / результат].

## Связь с предыдущими работами

Пользовательские истории являются продолжением анализа системы, выполненного в предыдущих практических работах:

- **ПР №1 — DFD** — определены основные процессы и потоки данных;
- **ПР №2 — ERD & Data Dictionary** — сформирована модель данных предметной области;
- **ПР №3 — Use Case** — определены акторы и варианты использования системы;
- **ПР №4 — User Story** — требования дополнительно представлены с точки зрения пользователей.

Таким образом, результаты ПР №4 используются как основа для последующей формализации требований в **ПР №5 — SRS**.
